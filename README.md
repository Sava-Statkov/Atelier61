# Румен Статков — сайт

Дигитална изложба, архив и летопис за художника Румен Статков (р. 1961, Бургас).
Сайтът е на български; английският е подготвен архитектурно и се включва по-късно.

Next.js 16 (App Router) · TypeScript · CSS Modules + дизайн токени · Supabase (база, снимки, вход) · Vitest · Playwright.

Творбите, снимките им, категориите и циклите са в Supabase и се управляват от **/admin**. Текстовете с източници
(биография, факти за циклите, изложби, летопис, цитати, истории, интервю) са в `src/content/*.ts`.

## Стартиране

```bash
npm install
npm run dev        # http://localhost:3300, админ: http://localhost:3300/admin
npm run check      # lint + типове + unit тестове
npm run build      # production build (чете творбите от базата в .env.local)
```

Изисква Node.js 20.9+ (проверено с 22). `.env.local` сочи към базата (вижте `.env.example`):
production проекта или локалното копие в Docker. **С production всичко, променено в админа, е на живо.**

### Локално копие на базата (за опити и тестове)

Нужен е Docker Desktop (пуснат).

```bash
npm run db:start   # пуска локалния Supabase (данните остават между рестартите)
npm run db:admin   # локален тестов админ: admin@atelier61.test, паролата е в .env.test.local
npm run db:seed    # 400 ясно отбелязани тестови творби; `npm run db:seed -- --clean` ги маха
npm run db:stop
```

За да работи сайтът с локалната база, сменете двата реда в `.env.local` с коментираните под тях.
Таблото на локалната база: http://127.0.0.1:54323.

### Тестове

| Команда | Какво проверява |
| --- | --- |
| `npm test` | masonry, адреси, опашката на импорта, целостта на текстовете |
| `npm run test:db` | кой какво може да чете и пише в базата (локално) |
| `npm run test:e2e` | админът от входа до изтриването, срещу production build и **локалната** база |
| `npm run check:refs` | творбите и циклите, споменати в текстовете, съществуват в базата от `.env.local` |

## Структура

```
supabase/migrations/   схемата на базата, правилата за достъп, хранилището, началното съдържание
supabase/tests/        тестове на правата
src/app/[lang]/        публичните страници
src/app/admin/         админът (вход, творби, импорт, категории и цикли, файлове)
src/lib/artworks/      четене на творбите от базата (кеш, публичните заявки)
src/lib/admin/         обработка и качване на снимки, опашката на импорта
src/lib/supabase/      връзката със Supabase и типовете на базата (`npm run db:types`)
src/components/gallery/ галерията „Творби“ (masonry, филтри, безкрайно скролване)
src/content/           текстовете с източници; series.ts се свързва с циклите в базата по адрес
src/assets/            снимки от оформлението и портретът (статичен import)
docs/                  арт дирекция, как се добавя съдържание, референции
```

## Адреси

| Адрес | Страница |
| --- | --- |
| `/` | Начало: творбата, избрана в админа, интервю, цикли, години, истории, биография |
| `/tvorbi`, `/tvorbi/<slug>` | Всички творби (филтри: `?kategoriya=zhivopis&cikal=tanc`) · отделна творба с лупа |
| `/cikli/<slug>` | Цикъл |
| `/<slug>` | Практика (`kind: "practice"` в `series.ts`), напр. `/risuvane-na-zhivo` |
| `/letopis`, `/istorii/<slug>`, `/intervyu`, `/kontakt` | Летопис, история, интервю, контакт |
| `/admin` | Админ (само за профила с роля admin) |

## Публикуване

Хостинг за Next.js 16 с Node (Vercel, Netlify, VPS с `npm run build && npm start`). Настройки на средата:

| Променлива | Стойност |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | `https://<project-ref>.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | публичният ключ (Project Settings → API Keys) |
| `NEXT_PUBLIC_SITE_URL` | каноничният адрес на сайта, без наклонена черта накрая |
| `NEXT_PUBLIC_NOINDEX` | `true` само за тестов сървър |

Таен ключ (`service_role` / secret) не е нужен и не се слага никъде. Нова творба не изисква нов build:
админът опреснява страниците при всяка промяна.

При пускането: в `src/content/site.ts` сложете `brandInTitle: true`. Изписването на марката („Atelier 61“ или
„Ателие 61“) е в `site.brand`.

## Ограничения на безплатния план на Supabase

- 1 GB за снимки (около 1500–2500 снимки); заетото място се вижда в **Админ → Файлове**.
- Проект без активност 7 дни заспива; кешираните страници продължават да се показват.
- Няма автоматични резервни копия: пазете оригиналните снимки и при голям импорт експортирайте таблиците
  (Supabase → Table Editor → Export).

Шрифтът Sofia Sans (Lettersoup) е под SIL Open Font License и се хоства от самия сайт чрез `next/font`.

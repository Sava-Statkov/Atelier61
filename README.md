# Румен Статков — сайт

Дигитална изложба, архив и летопис за художника Румен Статков (р. 1961, Бургас).
Сайтът е на български; английският е подготвен архитектурно и се включва по-късно.

Next.js 16 (App Router, статично генериране) · TypeScript · CSS Modules + дизайн токени · Vitest.
Без база данни, без бекенд, без бисквитки, без външни скриптове.

## Стартиране

```bash
npm install
npm run dev        # http://localhost:3300 — работна версия: показва и непотвърденото с бележки
npm run build      # публична версия: само потвърдено и цитирано съдържание
npm start
npm run check      # lint + типове + тестове за целостта на съдържанието
```

Изисква Node.js 20.9+ (проверено с 22).

## Структура

```
src/content/        съдържанието — творби, цикли, изложби, летопис, цитати, източници, филми, истории
src/content/types.ts  моделът на данните и правилата за проверка
src/lib/            заявки към съдържанието, правила за публикуване, дати, цитиране, медии
src/i18n/           езици (bg активен, en подготвен) и текстовете на интерфейса
src/components/     art (творби, окачване, лупа), film, room (каменна плоча, светлинна линия, лъчи), text, layout
src/styles/         tokens.css (цветове, шрифт, отстояния), rooms.css (стаите), fonts.ts
src/app/[lang]/     страниците
public/media/       снимки и медия на съдържанието (вижте docs/assets.md)
src/assets/room/    изображения от оформлението (камъкът под началния екран, акварелът на футъра)
docs/               арт дирекция, медия и съдържание, референции
scripts/media-manifest.mjs   чете размерите на снимките преди dev/build
```

## Адреси

| Адрес | Страница |
| --- | --- |
| `/` | Начало: творба на стената, интервю, цикли, години, истории, биография |
| `/tvorbi`, `/tvorbi/<slug>` | Всички творби (филтри в адреса: `?cikal=tanc&tehnika=oil`) · отделна творба с лупа и детайли |
| `/cikli/<slug>` | Цикъл |
| `/<slug>` | Практика, която не е цикъл (`kind: "practice"` в `series.ts`), напр. `/risuvane-na-zhivo`. Старият адрес `/cikli/<slug>` пренасочва тук |
| `/letopis` | Летопис (`/letopis#g-2007` води към година) |
| `/istorii/<slug>` | История |
| `/intervyu` | Интервюто |
| `/kontakt` | Контакт |

Българският е без префикс. Английският ще бъде под `/en/…` — включва се в `src/i18n/config.ts`.

## Съдържание и проверка

Всяко твърдение има статус (`confirmed`, `sourced`, `unconfirmed`, `placeholder`) и източници.
Публично излизат само `confirmed` и `sourced` с източник. Подробно: [docs/assets.md](docs/assets.md).

Първоначалното съдържание е събрано от четири публикации (НАИМ-БАН 2007, Радио България 2024,
Epoch Times България 2025, БНР „Христо Ботев“ 2026) и е отбелязано като `sourced` — чака преглед
от художника. Двете истории са със статус „чака преглед“ и не излизат публично.

## Какво липсва

| | Къде | Сега |
| --- | --- | --- |
| Снимки на творбите | `public/media/artworks/`, `artworks.ts` | Сурово платно с надпис „Снимката на творбата предстои“ |
| Годините, техниките и размерите на „Конник“ и „Окото на света“ | `artworks.ts` | Скрити до проверка |
| Интервюто: постер, видео, субтитри, части, текст | `films.ts` | „Интервюто предстои да бъде заснето.“ |
| Контакти (имейл, телефон, Facebook адрес) | `site.ts` | Скрити; на страницата „Контакт“ — „Данните за контакт ще бъдат публикувани тук.“ |
| Домейн | `NEXT_PUBLIC_SITE_URL` | Не е зададен |
| Години на обучение, подробности за „Послание към света“ | `timeline.ts`, `series.ts` | Без дата / само заглавие |
| Снимки на ателието; автор на портрета | `public/media/photos/`, `site.ts` (`credit`) | Портретът в „Повече за художника“ е сложен, без посочен автор |
| Окончателна визия | `docs/art-direction.md` | Временна първа итерация по референциите |

## Публикуване

Всеки хостинг за Next.js 16 (Vercel, Netlify, VPS с `npm run build && npm start`).
Задайте `NEXT_PUBLIC_SITE_URL` (канонични адреси, sitemap). За тестов сървър — `NEXT_PUBLIC_NOINDEX=true`.

При пускането: в `src/content/site.ts` сложете `brandInTitle: true`, за да съдържат заглавията в таба и
името, и марката (`Румен Статков | Atelier 61`). Изписването на марката („Atelier 61“ или „Ателие 61“)
е в `site.brand` и важи и за горния ъгъл на сайта.

Шрифтът Sofia Sans (Lettersoup) е под SIL Open Font License и се хоства от самия сайт чрез `next/font`.
